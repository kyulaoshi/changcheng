# 🏯 长城竞速 · 만리장성 레이싱

한국어 뜻을 보고 **중국어 병음**을 입력하면 캐릭터가 만리장성을 달리는 **중국어 타자 게임**입니다.
학생들은 **각자 자기 기기**에서 단원과 연습 방식을 골라 제한 시간(기본 5분) 동안 **누가 가장 멀리 가는지** 도전합니다. 정답 1개는 100m입니다.

- **서버·데이터베이스·로그인 없음** — HTML/CSS/JavaScript 파일만으로 동작하고, GitHub Pages·Netlify에 올리면 끝입니다.
- **결과 확인** — 게임이 끝나면 학생 화면에 결과 카드(이름·단원·방식·날짜·거리·정확도)가 나옵니다. 선생님은 그 화면을 보고 확인합니다.

---

## 1. 게임 방식

첫 화면에서 **단원**(생활 중국어 교과서 1~10단원, 241단어)과 **연습 방식**을 고르고 시작합니다. 전체 단원도 고를 수 있습니다. 뜻이 같은 단어(예: 미안합니다 → duìbuqǐ · bù hǎoyìsi)는 어느 쪽을 쳐도 정답입니다.

| 연습 방식 | 화면에 나오는 것 | 입력 | 성조 채점 |
|---|---|---|---|
| ⌨️ 병음 따라 치기 | 병음 (+ 한자·뜻) | 보이는 병음 그대로 | 함 |
| 🎵 뜻 보고 병음+성조 | 한국어 뜻 | 병음 + 성조 | 함 |
| 🔤 뜻 보고 병음 | 한국어 뜻 | 병음 | 안 함 |

- **성조 입력**: 음절 뒤에 숫자를 치면 바로 기호로 바뀝니다 (`jia1ren2` → `jiārén`, `lv4` → `lǜ`). 경성은 숫자 없이 씁니다. 경성 음절은 어떤 성조를 써도 인정합니다.
- **병음 판정**: 대소문자·띄어쓰기·아포스트로피 무시, ü = v. 철자만 맞고 성조가 틀리면 "성조를 다시 확인해 보세요"가 나옵니다.
- 한/영을 깜빡해 `ㅔㅑㅜㅎ혀ㅐ`로 입력돼도 `pingguo`로 바꿔 채점하고 안내합니다.
- **최고 기록(유령)**은 학생 기기에 단원·방식별로 저장됩니다. 어디에도 전송되지 않습니다.

## 2. 파일 구성

```
changcheng-racing/
├── index.html        게임 (시작 · 이름/캐릭터 · 게임 · 결과 카드)
├── css/style.css     디자인
├── js/units.js       ★ 단원별 단어 + 연습 방식 3가지 (단어를 바꿀 때는 이 파일만)
├── js/app.js         게임 진행 (달리기·채점·유령·결과 카드)
├── js/pinyin.js      병음 비교 · 성조 숫자 → 기호 · 한글 자판 복원
├── js/endless.js     끝없는 만리장성 트랙
├── js/characters.js  캐릭터 6종
├── js/sound.js       효과음
├── js/common.js      공용 도구
├── assets/favicon.svg
├── netlify.toml / .nojekyll
```

**단어 바꾸기**: `js/units.js`에서 `unit('번호', '단원 제목', \`한국어 뜻|중국어|병음\`)` 형식으로 고칩니다. 병음은 `nǐ hǎo`나 `ni3 hao3` 둘 다 됩니다.

## 3. 올리는 방법 (한 번만, 10분)

**GitHub Pages**
1. https://github.com 가입 → **+ → New repository** → 이름 `changcheng-racing`, **Public** → Create
2. **uploading an existing file** → 압축을 푼 폴더 **안의 파일 전체**를 끌어다 놓기 → **Commit changes**
   (폴더째가 아니라 안의 파일들을 올려야 `index.html`이 맨 위에 옵니다)
3. **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**
4. 1~3분 뒤 주소가 생깁니다: `https://내아이디.github.io/changcheng-racing/`

**Netlify (더 빠름)**: https://app.netlify.com/drop 에 폴더를 통째로 끌어다 놓으면 바로 주소가 생깁니다.

> 파일을 더블클릭해서 여는 방식(`file://`)은 브라우저 보안 때문에 동작하지 않습니다. 컴퓨터에서 바로 써 보려면 폴더에서 `python -m http.server 8000` 실행 후 `http://localhost:8000`을 여세요. VS Code라면 Live Server 확장을 써도 됩니다.

## 4. 나눠 주기

올린 사이트 주소 하나만 알려 주면 됩니다. 학생은 주소를 열고 단원·방식을 골라 바로 시작합니다. 서버가 없어서 동시에 몇 명이 써도 비용이나 한도가 없습니다.

## 5. 자주 묻는 질문

| 질문 | 답 |
|---|---|
| 학생 기록을 모아서 볼 수 있나요? | 서버가 없어서 자동으로 모이지 않습니다. 결과 카드를 확인하거나 캡처를 받아 주세요. |
| 학생이 여러 번 할 수 있나요? | 네. 공식 기록이 필요하면 "첫 기록만 인정" 같은 규칙을 정해 주세요. |
| 인터넷이 끊기면? | 페이지가 한 번 열린 뒤에는 인터넷 없이도 끝까지 할 수 있습니다. |
| 소리가 안 나요 | 화면을 한 번 클릭해야 소리가 켜집니다(브라우저 규칙). 오른쪽 위 🔊 버튼도 확인하세요. |
