# 🏯 长城竞速 · 만리장성 레이싱

한국어 뜻을 보고 **중국어 병음**을 입력하면 캐릭터가 만리장성을 달리는 **중국어 타자 게임**입니다.
학생들은 **각자 자기 기기**에서 제한 시간(기본 5분) 동안 **누가 가장 멀리 가는지** 도전합니다. 정답 1개는 100m입니다.

- **서버·데이터베이스·로그인 없음** — HTML/CSS/JavaScript 파일만으로 동작하고, GitHub Pages·Netlify에 올리면 끝입니다.
- **선생님은 단어장 링크만 만들어 나눠 줍니다** — 단어가 링크 안에 들어 있어서 따로 저장할 곳이 필요 없습니다.
- **결과 확인** — 게임이 끝나면 학생 화면에 결과 카드(이름·단어장·날짜·거리·정확도)가 나옵니다. 선생님은 그 화면을 보고 확인합니다.

---

## 1. 전체 구조

```
 선생님                                         학생 (각자 기기)
 ─────────────────────────────                  ──────────────────────────────────────
 teacher.html  단어장 링크 만들기                 index.html#w=...  (링크·QR로 열기)
  · 이름·제한 시간·순서 섞기                       · 단어장 확인 → 이름·캐릭터 → 3·2·1
  · 단어 넣기 (기본 주제 8종 / 엑셀 붙여넣기 / CSV)   · 한국어 뜻 → 병음 입력 → 정답마다 100m 전진
  · → 학생용 링크 + QR 코드 (자동 생성)            · 20개(2km)마다 구간 돌파, 연속 정답 부스터
  · QR 크게 띄우기 · 링크 복사 · 인쇄              · 👻 이 기기 최고 기록이 유령으로 함께 달림
                                                 · 시간 종료 → 결과 카드 + 단어 복습
```

- **단어장 링크**: `index.html#w=XXXX` — `#` 뒤에 제목·제한 시간·단어 목록을 압축해 넣습니다. `#` 뒷부분은 서버로 전송되지 않아서 정적 호스팅에서 그대로 동작합니다. 단어 20개 기준 링크는 약 500자이고, QR 코드로 바로 찍을 수 있습니다.
- **링크 없이 열면** 첫 화면에서 기본 주제(기본 20단어·인사·가족·숫자·음식·학교생활·동사·날짜)를 골라서 합니다.
- **저장되는 것**: 학생 기기 브라우저에 그 단어장의 최고 기록(유령용)과 마지막 캐릭터만 저장됩니다. 선생님 컴퓨터에는 "이 컴퓨터에 저장"한 단어장만 저장됩니다. 어디에도 전송되지 않습니다.
- **병음 판정**: 대소문자·성조 기호·성조 숫자·띄어쓰기·아포스트로피를 무시하고, ü = v = u로 봅니다. 철자가 틀리면 오답입니다. 한/영을 깜빡해 `ㅔㅑㅜㅎ혀ㅐ`로 입력돼도 자판 위치대로 `pingguo`로 바꿔 채점하고 안내합니다.

## 2. 파일 구성

```
changcheng-racing/
├── index.html        학생 게임 (시작 · 이름/캐릭터 · 게임 · 결과 카드)
├── teacher.html      선생님용 단어장 링크 만들기
├── guide.html        선생님 사용 설명서 (인쇄 가능)
├── css/style.css     게임 디자인 (트랙·캐릭터 애니메이션·결과 카드·반응형)
├── css/teacher.css   단어장 링크 만들기 화면 디자인
├── js/app.js         학생 게임 진행 (달리기·채점·구간·유령·결과 카드)
├── js/teacher.js     단어장 편집 → 링크·QR 생성, 보관함, CSV
├── js/wordlink.js    단어장 ↔ 링크 변환 (압축)
├── js/words.js       기본 단어 + 주제별 단어장 8종 + 엑셀 붙여넣기 해석
├── js/pinyin.js      병음 비교 규칙 · 한글 자판 → 영문 복원
├── js/race.js        만리장성 트랙 (레인·봉화대·결승 패루·부스터)
├── js/characters.js  캐릭터 6종 SVG (판다·용·호랑이·토끼·원숭이·쿵푸)
├── js/sound.js       효과음 (Web Audio로 합성, 음원 파일 없음)
├── js/qr.js          QR 코드 생성기 (외부 라이브러리 없음)
├── js/common.js      토스트·모달·폭죽·CSV 등 공용 도구
├── assets/favicon.svg
├── netlify.toml      Netlify 설정 (빌드 없음)
└── .nojekyll         GitHub Pages 설정
```

**기본 단어 바꾸기**: 링크 없이 열 때 나오는 주제별 단어장은 `js/words.js`의 `DEFAULT_WORDS`, `WORD_PRESETS`에 있습니다. 보통은 코드를 고치지 않고 단어장 링크를 만들어 쓰면 됩니다.

## 3. 올리는 방법 (한 번만, 10분)

**GitHub Pages**
1. https://github.com 가입 → **+ → New repository** → 이름 `changcheng-racing`, **Public** → Create
2. **uploading an existing file** → 압축을 푼 폴더 **안의 파일 전체**를 끌어다 놓기 → **Commit changes**
   (폴더째가 아니라 안의 파일들을 올려야 `index.html`이 맨 위에 옵니다)
3. **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**
4. 1~3분 뒤 주소가 생깁니다: `https://내아이디.github.io/changcheng-racing/`

**Netlify (더 빠름)**: https://app.netlify.com/drop 에 폴더를 통째로 끌어다 놓으면 바로 주소가 생깁니다.

> 파일을 더블클릭해서 여는 방식(`file://`)은 브라우저 보안 때문에 동작하지 않습니다. 컴퓨터에서 바로 써 보려면 폴더에서 `python -m http.server 8000` 실행 후 `http://localhost:8000`을 여세요. VS Code라면 Live Server 확장을 써도 됩니다.

## 4. 다른 선생님들께 나눠 주기

- 올린 사이트 주소 하나만 알려 주면 됩니다. 각자 `…/teacher.html`에서 자기 단어장 링크를 만들어 씁니다. 가입이나 설정은 필요 없습니다.
- 서버가 없으므로 사용하는 선생님·학생이 아무리 많아도 비용이나 사용량 한도가 없습니다. GitHub Pages나 Netlify가 파일만 보내 줍니다.
- 만든 단어장 링크를 다른 선생님께 보내면 그대로 쓰거나, `teacher.html`의 **받은 링크로 고치기**에 붙여넣어 고쳐 쓸 수 있습니다.
- 사용 설명서: `…/guide.html` (인쇄해서 연수 자료로 써도 됩니다)

## 5. 수업에서 쓰는 순서

1. `teacher.html`에서 단어장 이름·제한 시간을 정하고 단어를 넣습니다.
2. **🖥️ QR 크게 띄우기**로 TV에 QR을 띄우거나 **🔗 링크 복사**로 클래스룸·메신저에 올립니다.
3. 학생들이 링크를 열어 이름·캐릭터를 고르고 출발합니다.
4. 끝나면 학생 화면의 **결과 카드**를 확인합니다. 손을 들게 하거나 캡처해서 제출하게 하면 됩니다.

## 6. 테스트 방법

1. 사이트를 열고 첫 화면에서 주제를 골라 한 판을 해 봅니다. 정답·오답 효과, 3·5연속 부스터, 20개마다 구간 돌파, 시간 종료 후 결과 카드를 확인하세요.
2. **다시 도전**을 눌러 👻 유령(방금 기록)이 옆 레인에서 달리는지 확인합니다.
3. `teacher.html`에서 단어장을 만들고, 휴대폰 카메라로 QR을 찍어 같은 단어가 나오는지 확인합니다.
4. 링크를 메신저로 보내 다른 기기에서 열어 봅니다. 링크가 잘리면 "단어장 링크가 잘렸어요" 안내가 나옵니다.

> 개발 중 자동 테스트(30개 항목, 모두 통과)
> - **단어장 링크 만들기**: 링크 생성, QR 스캔 결과가 링크와 정확히 일치, 큰 QR 스캔, 이 컴퓨터에 저장, 엑셀 한글 CSV 덧붙이기, 받은 링크로 다시 고치기·제한 시간 복원
> - **학생 게임**: 링크의 단어장 표시, 이름 필수, 3·2·1, 오답·대문자 입력, 구간 돌파, 시간 종료 후 결과 카드와 최고 기록
> - **유령·기타 화면**: 다시 도전 시 유령 레인이 나타나고 스스로 움직임, 링크 없이 주제 선택, 잘못된 링크 안내, 모바일 화면 가로 넘침 없음
> - **전체**: 모든 페이지에서 JS 오류 없음, 외부 서버로 가는 요청 없음(글꼴 제외)

## 7. 자주 묻는 질문

| 질문 | 답 |
|---|---|
| 학생 기록을 모아서 볼 수 있나요? | 서버가 없어서 자동으로 모이지 않습니다. 결과 카드를 확인하거나 캡처를 받아 주세요. |
| 학생이 여러 번 할 수 있나요? | 네. 공식 기록이 필요하면 "첫 기록만 인정" 같은 규칙을 정해 주세요. |
| 단어는 몇 개까지 넣을 수 있나요? | 링크로는 수백 개도 됩니다. QR 코드는 약 100개까지 만들 수 있지만, 쉽게 찍히려면 40개 이하를 권장합니다. |
| 인터넷이 끊기면? | 페이지가 한 번 열린 뒤에는 인터넷 없이도 끝까지 할 수 있습니다. |
| 소리가 안 나요 | 화면을 한 번 클릭해야 소리가 켜집니다(브라우저 규칙). 오른쪽 위 🔊 버튼도 확인하세요. |
| 한자가 깨진 CSV | 엑셀에서 **CSV UTF-8**로 저장하거나, 칸을 복사해 붙여넣으세요. |
